# A.T.O.M.I.X. Blockbench Plugins (Engine & Combat)

This package includes both Blockbench plugins:
1. `atomix_tools.js` — **AtomiX Engine**: Validates model/animation bone names and exports universal `.pack.json` state files.
2. `atomix_combat_tools.js` — **AtomiX Combat**: Inserts combat phase markers (`phase:windup`, `phase:strike`, `phase:hitstop`, `phase:recover`, `phase:parry`), validates attack hitboxes, and exports universal fighting movesets for any entity or custom entity.

## Installation
In Blockbench, go to **File > Plugins > Load Plugin from File** and select `atomix_tools.js` and `atomix_combat_tools.js`.
